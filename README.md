# Plain – minimalist Android launcher

## Get the APK (no Android Studio needed)
1. Create a free GitHub repo and upload everything in this folder (keep the `.github` folder).
2. Open the repo's Actions tab and wait for "Build APK" to finish (about 3 minutes).
3. Open the finished run, download `plain-launcher-apk`, unzip it, and copy `app-debug.apk` to your phone.
4. Tap the APK to install (allow "install unknown apps" if asked).
5. Press Home and choose Plain, then "Always".

## Or with Android Studio
Open this folder, let Gradle sync, then Run on your phone.

## Using it
- Swipe up or tap All apps. Type to search; Enter opens the top match.
- Long-press an app: pin to home, mindful delay, app info, uninstall.
- Long-press empty home space: settings (delay length, 12/24h clock, theme).
